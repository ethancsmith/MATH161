\begin{theorem}[Substitution rule]
If $u=g(x)$ is a differentiable function whose range is in an interval $I$, and $f$ is continuous on $I$, then
\begin{equation*}
\int f(g(x))g'(x)\dee x = \int f(u)\dee u.
\end{equation*}
\end{theorem}

\begin{remark}
Formally, this is just the chain rule written in reverse (i.e., for antidifferentiation).
\end{remark}
